## 本週三大重點

- AI 技術圈這週話題圍繞 Claude 生態系展開：Anthropic 發布新一代輕量模型 Haiku 5.5（OSWorld 2.1 分數由前代 15.7% 大幅躍升至 72.4%）、Claude Code 連番更新 Mods 外掛架構，馬斯克旗下 Grok Bot 更宣布將視任務呼叫 Claude Opus 5.5 等外部模型，「多模型路由」成為討論焦點；OpenAI 同週一口氣公開 722 篇 AI 生成數學論文，則在學術圈掀起「AI 研究成果該如何查證與歸功」的爭論。
- 美股本週因中東情勢升溫、公債殖利率走高而劇烈震盪：10/8 那斯達克因油價飆漲與美債殖利率衝上逾 24 年新高而重挫，10/12 再因沙烏地機場遇襲牽動油價走高拉回，但 10/9 強彈收復失土、標普 500 一度觸及歷史新高 7,844.52 點；台積電第三季營收創歷史新高（1 兆 4,942 億元、年增 50.9%），法說會於今日（10/15）登場。

## AI 技術圈熱議

- **Claude Haiku 5.5 登場，成為 Claude Code 新預設模型**：Anthropic 發布新一代小型模型 Haiku 5.5，官方 benchmark 顯示 OSWorld 2.1 從前代的 15.7% 大幅提升到 72.4%、Terminal-Bench 4.0 由 0% 衝到 39.2%，定價維持每百萬輸入 token $0.10（超過 100K 則 $0.50），比 Haiku 4.5 平均便宜約 75%；Claude Code 隨即將其納入預設模型選項。（2026-10-07～10-08，[The New Stack](https://thenewstack.io/anthropic-claude-haiku-5-5/)、[Let's Data Science](https://letsdatascience.com/news/anthropic-releases-claude-haiku-55-for-high-volume-tasks-1c6260b4)）
- **Claude Code 連環更新，新增 Mods 外掛架構**：Claude Code 在 10/1～10/8 間一口氣推出多個版本（v2.1.287～v2.1.294），新增可讓外掛修改更深層行為的「Claude Mods」、市集直接安裝外掛、可調整 sub-agent 思考強度，並修正權限提示遺失、hook 規則誤判等問題。（2026-10-08，[Havoptic Claude Code Releases](https://www.havoptic.com/releases/claude-code/2026/10)）
- **馬斯克宣布 Grok Bot 改採多模型路由，將呼叫 Claude Opus 5.5**：Elon Musk 在 X 上發文表示 xAI 的 Grok Bot 未來會依任務自動選用「最佳後端模型」，點名包含 Claude Opus 5.5、Midjourney、Suno 等外部模型，打破 Grok Bot 先前只用自家模型的作法，引發「AI 公司互相呼叫對手模型」的討論熱潮。（2026-10-07，討論延燒至 2026-10-09，[Metirai](https://www.metirai.com/blog/grok-bot-routes-claude-opus-midjourney-suno-model-routing-2026)）
- **OpenAI 一次釋出 722 篇 AI 生成數學論文引發驗證爭議**：OpenAI 公開由內部未命名模型產生的 722 篇數學手稿（歸類為 372 組相關成果，橫跨 17 個數學領域），其中包含「唯一賽局猜想（Unique Games Conjecture）」等重大宣稱，但官方坦承部分結果未經 Lean 形式化驗證，已有成果被撤回或修正，數學社群正熱烈討論 AI 研究成果該如何歸功與查證。（2026-10-06～10-08，[Let's Data Science](https://letsdatascience.com/blog/openai-posted-722-ai-written-math-papers-kept-the-prompts)、[YourStory](https://yourstory.com/ai-story/openai-ai-open-maths-problems-solved)）
- **Mistral 發布兆參數級模型 Large 4「Le Chonk」**：法國新創 Mistral 推出總參數約 1 兆、啟用參數 490 億的 Large 4，支援圖文輸入，宣稱在多項開放權重模型中排名領先歐美同類模型；API 已可預覽，開放權重預計 10 月底釋出，為該公司三週前完成 30 億歐元募資（估值逾 210 億歐元）後的首個重大發布。（2026-10-06，[BornCity](https://borncity.com/news/mistral-large-4-modellgewichte-sollen-am-27-oktober-2026-erscheinen/)、[Let's Data Science](https://letsdatascience.com/news/mistral-releases-trillion-parameter-large-4-model-7191b865)）
- **GitHub Copilot CLI 連續三週更新，強化沙箱與權限控制**：GitHub Copilot CLI 在 10 月初連發 v1.0.91、v1.0.92、v1.0.93 三個版本，加入 Windows 沙箱支援、環境選擇器，並讓「即時沙箱（real-time sandboxing）」對所有使用者開放，被視為持續追趕 Claude Code、Cursor 的動作之一。（2026-10-01～10-07，[Havoptic GitHub Copilot Releases](https://www.havoptic.com/releases/github-copilot/2026/10)）
- **Anthropic 新規禁止「虐待」Claude**：Anthropic 更新使用政策，明文禁止使用者「持續、無正當目的地」對 Claude 做出殘忍或辱罵行為，但排除一般挫折發洩、暗黑創作或測試研究；政策將於 11 月 12 日生效，被視為 Anthropic 模型福祉（model welfare）研究路線的延伸。（2026-10-08，[Dealroom](https://dealroom.co/news/161094-anthropic-bans-sustained-abusive-or-cruel-behavior-toward-claude-in-new/)）
- **TechCrunch Disrupt 2026 登場，AI Coding Agent 安全缺口成焦點**：一年一度的 TechCrunch Disrupt 在舊金山 Moscone West 舉行（10/13～10/15），Anthropic、OpenAI 雙雙受邀站上 AI 主題舞台；議程聚焦「SaaS reckoning」與日益浮現的「agent security gap」，並有專場討論 Anthropic 如何在內部大規模運用 coding agent 艦隊進行軟體工程工作。（2026-10-13～10-15，[InfoWorld](https://infoworld.com/article/4217752/techcrunch-disrupt-whats-next-for-ai-and-software-development.html)）
