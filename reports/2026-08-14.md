## AI 技術圈熱議

- **Claude Code「Auto Mode」8/14 正式成為新對話預設**：Anthropic 先前宣布自 8/14 起 Pro／Max／Team 方案的新工作階段將預設開啟 Auto Mode（以分類器攔截危險指令、取代逐一核准），本週正式生效上路，權限審批機制的實際使用回饋成為社群後續觀察重點。（8/9～8/14，[TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/)、[9to5Mac](https://9to5mac.com/2026/08/07/psa-claude-code-enabling-auto-mode-as-default-next-week-anthropic-says/)）
- **Claude Code 新增「跨 Session 通訊」功能**：v2.1.224 版讓不同工作階段、甚至不同終端機視窗能透過 ListAgents／SendMessage 互相傳訊、同步進度，減少工程師在多視窗間反覆解釋上下文的麻煩；目前僅支援 macOS 與 Linux（含 WSL2），尚不支援原生 Windows，台灣科技媒體《數位時代》Podcast 亦於 8/11 專題報導此功能。（8/7，[9to5Mac](https://9to5mac.com/2026/08/07/claude-code-now-lets-sessions-talk-to-each-other-on-macos/)）
- **Claude Code 接連修補 Remote Control 與 MCP OAuth 問題**：8/12 的 v2.1.229 新增 `claude remote-control --continue` 可接續最近一次遠端工作階段，並補上 SSE 心跳封包避免長思考時在 Vertex／Bedrock 因閒置逾時斷線；8/13 的 v2.1.231 進一步修正使用預先註冊 OAuth 用戶端（如 Slack）的 MCP 伺服器登入失敗問題，是此前不少使用者反映的關鍵 bug。（8/12～8/13，[Claude Code Changelog](https://code.claude.com/docs/en/changelog)）
- **GitHub Copilot 週更：新增 `/btw` 側邊提問、開源模型 Kimi K3 轉正**：開發者可用 `/btw` 在不打斷主 agent 任務的情況下另開側邊聊天並共享上下文；同時新增可即時檢視 diff 的混合式 Markdown 編輯器，月之暗面開源模型 Kimi K3 也正式轉為 GA 可選模型，讓習慣 Copilot 介面的開發者能以原廠牌價低成本試用這個開源大模型。（8/7，[GitHub Changelog](https://github.blog/changelog/2026-08-07-github-copilot-weekly-releases-august-3/)）
- **GitHub Copilot Web 版擴充對話管理功能**：新增快速存取歷史對話、可縮小視窗背景執行，以及 token 用量指示，方便使用者追蹤額度消耗，反映 Copilot 團隊近期主打「不打斷代理」的體驗改善方向。（8/10，[GitHub Changelog](https://github.blog/changelog/2026-08-10-copilot-on-web-expands-conversation-controls/)）
- **Cursor 取得 AIUC-1「AI Agent 安全標準」認證**：Cursor 的 agent 通過涵蓋 12 個類別、數千項技術評測的 AIUC-1 標準，成為少數取得此認證的編碼工具，被視為企業導入 AI coding agent 時的重要信任指標，呼應近期業界對 agent 自動化安全性的高度關注。（8/13，[Cursor Blog](https://cursor.com/blog)）
- **xAI 發布 Grok 4.6，同步上線 Cursor**：新模型具備 50 萬 token 上下文窗口，官方宣稱 10 項基準測試全面優於前代 Grok 4.5，同步開放於 Cursor、Grok Build 與 API，首週提供 Cursor 內雙倍用量優惠；社群反應正反並存，一派肯定其長任務處理能力提升，另一派質疑「跑分亮眼、實戰待驗證」。（8/12，[Cursor Blog](https://cursor.com/blog/grok-4-6)）
- **Composio 實測 4 種 Agent Harness 搭開源模型 DeepSeek V4 Flash**：以 30 項 agentic 任務比較 Claude Code、Codex、OpenCode、Oh My Pi 四種框架表現，Oh My Pi 完成率最高（17/30）但速度最慢，Claude Code 速度最快（中位數 122.7 秒完成任務），在開發者社群引發「該用哪種 harness 搭開源模型」的討論。（8/12，[Composio](https://composio.dev/content/best-agent-harness-deepseek-v4-flash)）
- **r/LocalLLaMA 社群討論熱度居高不下**：統計顯示該版（約 79.8 萬名成員）平均每日發文 53.6 篇，本週熱門貼文平均約 1,000 個讚、255 則留言，話題聚焦本地部署心得與 GLM-5.2、Kimi K2.7、DeepSeek V4 Flash、Qwen 3.6 等開源模型的實測比較。（查詢於 8/14，[GummySearch](https://gummysearch.com/r/LocalLLaMA/)）
- **〔資安一句話摘要〕惡意 MCP 伺服器恐誘導 AI 編碼代理外洩機密**：資安研究人員揭露一種攻擊手法，可讓惡意 MCP 伺服器誘導 Claude Code 等 AI 編碼代理外洩 SSH 金鑰、原始碼等機密資料；影響對象為串接不明來源 MCP 伺服器的開發團隊，建議只安裝受信任來源的 MCP 伺服器並限制其存取權限。（8/12，[The Hacker News](https://thehackernews.com/2026/08/malicious-mcp-servers-can-split.html)）
