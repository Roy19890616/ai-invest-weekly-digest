# AI + 投資週報 2026-08-13

> 彙整期間：2026-08-06 ～ 2026-08-13

## 本週三大重點

- AI 圈本週最熱話題：Claude Code 的 Auto mode 將成預設引爆權限審批論戰，社群共識逐漸轉向「agent 自動化可以，但要關進沙盒」，Docker 順勢推出 agent 專用拋棄式沙盒。
- 美國 7 月 CPI 年增率降至 3.4%、非農就業意外減少 2.3 萬人，但通膨仍遠高於 2% 目標，市場對 Fed 年內降息的預期幾乎出局，下週焦點轉向 8/19 的 FOMC 會議紀要。
- 台股創新高：加權指數 8/12 收 45,518 點站穩 45,500 關卡，台積電 7 月營收年增 44.7% 連 3 個月創單月新高，鴻海、廣達、聯發科等 AI 供應鏈數據全面報喜。

## AI 技術圈熱議

- **Claude Code「Auto mode」將成預設，權限審批論戰開打**：Anthropic 宣布用分類器自動放行／攔截指令（宣稱可擋約 89% 危險指令）並於 8/14 生效，HN 上 313 則留言分成幾派——有人主張「靠 prompt 約束 agent 就已經輸了」應用 VM／容器沙盒，有人說 permission fatigue 才是真問題。（8/11，[Hacker News](https://news.ycombinator.com/item?id=49239021)、[iThome](https://www.ithome.com.tw/news/177994)）
- **Docker 推出「Docker Sandboxes」**：給 AI agent 的拋棄式隔離沙盒，正好接上 Auto mode 論戰；社群共識逐漸變成「agent 要自動化可以，但請關進沙盒」。（8/10，[Docker via Hacker News](https://www.docker.com/products/docker-sandboxes/)）
- **coding agent 共通信任風險曝光**：Novee Security 揭露 Claude Code、Gemini CLI、Codex 可被惡意 GitHub issue 注入內容，達成 RCE、外洩機密、持續污染後續 agent——對用 agent 自動處理 issue 的團隊是實務警訊。（8/10，[iThome](https://www.ithome.com.tw/news/178005)）
- **Cursor 口碑危機延燒，用戶出走潮**：開發者抱怨不透明 rate limit、達量後「越用越笨」疑似逼升級，不少人取消訂閱轉用 Claude Code，並搭配 OpenRouter（Qwen 3 Coder、Kimi K2）做補全。（8/10 前後，[InfoQ 中文](https://www.infoq.cn/article/06ov3mEaQskNgP6gM9od)）
- **Meta 重返開源：釋出 Muse Glimmer 30B 開放權重模型**：30B dense、120K context、主打本地 agentic 工作流，NVIDIA 與 AMD 隔天就出本地部署教學；Zuckerberg 以 6,500 字宣言主張 AI 不該由少數公司壟斷。（8/10，[FT](https://www.ft.com/content/4e3957f8-ea7c-4c46-a3de-cdce8e526878)、[NVIDIA 部署指南](https://developer.nvidia.com/blog/run-local-agentic-ai-workflows-with-metas-muse-glimmer-on-nvidia/)）
- **Claude 開始標記 AI 生成內容**：文字藏機器可讀浮水印、檔案附 C2PA 來源資訊；社群熱議偵測可靠性、能否被移除、對正當使用者的影響。（8/10，[Anthropic 支援頁](https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content)、[iThome](https://www.ithome.com.tw/news/178044)）
- **Oracle 禁止 AI 生成程式碼進入 OpenJDK**：開源社群激辯「怎麼定義與稽核 AI 生成」、大型專案該不該一刀切，被視為最具指標性的 AI 貢獻政策表態。（8/7，[Hacker News](https://news.ycombinator.com/front)）
- **Google 稱「Go 是 AI 輔助軟體工程的理想語言」引發語言大戰**：支持方認為 Go 簡單語法＋快速編譯＋強型別讓 agent 迭代驗證特別順；反方認為測試與工具鏈完備度才是關鍵、與語言無關。（8/11，[Google Developers Blog](https://developers.googleblog.com/why-go-is-an-ideal-language-for-ai-assisted-software-engineering/)）
- **兩篇 HN 破 600 分的大論戰**：「AI 吃掉網路，網際網路的集體記憶正在消失」（926 分）談 AI 摘要讓內容網站流量枯竭；「AI 正在消滅軟體工程的中產階級」（697 分）認為 AI 讓資深者更強、入門更容易，但中間層價值被壓縮，code review 能力成新分水嶺。（8/10–8/12，[The Walrus](https://thewalrus.ca/google-search-is-dying/)、[原文](https://blog.florianherrengt.com/ai-removing-middle-class-software-engineering.html)）

## 總體經濟

- **7 月非農就業意外負成長**：減少 2.3 萬人（預期增加 8–9 萬人），失業率降至 4.1%（主因勞參率下滑至 61.4%），5、6 月合計下修 10.3 萬人；平均時薪年增率 3.2%、為 2021 年 5 月以來最低。（8/7，[CNBC](https://www.cnbc.com/2026/08/07/jobs-report-july-2026.html)）

- **新台幣維持偏強格局**：8/6 收 32.261 元、8/12 收 32.278 元；今年以來美元指數下跌約 8.84%，台灣對美順差破千億美元加上 AI 供應鏈出貨暢旺，出口商與外資拋匯支撐台幣。（8/6–12，[MoneyDJ](https://www.moneydj.com/kmdj/news/newsviewer.aspx?a=a99b89d3-1415-4c8f-8639-4940045e0b0d)、[自由財經](https://ec.ltn.com.tw/article/breakingnews/5536209)）
