# AI + 投資週報

由排程雲端 Agent 每週一台灣時間 08:00 自動產出，彙整過去一週的 AI 產業與投資市場重點訊息。

## 內容範圍

- AI 產業動態（模型發布、大廠動作、政策法規、重要應用）
- 美股／科技股（大盤、科技巨頭、AI 相關個股）
- 台股（大盤、電子供應鏈、法人動向）
- 總體經濟（Fed／央行、通膨利率、匯率）
- 下週觀察（財報、經濟數據、重要事件）

## 檔案結構

```
reports/
  YYYY-MM-DD.md   ← 每週一份，以產出當天日期命名
```

## 聲明

所有內容為公開新聞之彙整摘要，僅供個人參考，**非投資建議**。
