## AI 技術圈熱議

- **輝達宣布以近 130 億美元收購開源模型平台 Hugging Face**：輝達 9/3 證實將收購開源 AI 模型社群龍頭 Hugging Face，交易預計 2027 年上半年完成，被視為輝達強化自身開源 AI 生態系布局、對抗封閉模型陣營的重要一步。（9/3，[CNBC](https://www.cnbc.com/2026/09/03/nvidia-agrees-to-buy-hugging-face-for-almost-13-billion-ai-expansion.html)）
- **OpenAI 發布 GPT-6 Astra，社群對「基準測試飽和」提出質疑**：OpenAI 9/3～9/4 陸續開放新旗艦模型 GPT-6 Astra，在 ARC-AGI-3 等基準測試取得近滿分成績，但業界對其「可監控性」與「亮眼分數是否掩蓋深層對齊問題」意見兩極。（9/3～9/4，[CNBC](https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html)／[Al Jazeera](https://www.aljazeera.com/economy/2026/9/4/openai-unveils-gpt-6-astra-amid-rising-scrutiny-and-safety)）
- **MBZUAI 研究院釋出全開源模型 K2 Horizon**：阿布達比 Institute of Foundation Models 發布六款全開源模型（0.9B 至 375B 參數），完整釋出權重、程式碼與訓練資料並採 Apache 2.0 授權，在推理、數學、程式碼與代理任務多個尺寸級距皆創下開源模型最佳成績，本地部署圈熱議。（9/3，[HPCwire](https://www.hpcwire.com/aiwire/2026/09/03/institute-of-foundation-models-releases-fully-open-k2-horizon-models-with-weights-code-and-training-data/)）
- **Claude Code v2.1.260 新增即時 Diff 面板，並修正誤鎖指令 bug**：Anthropic 釋出 v2.1.260，加入可即時查看未提交變更的 /diff 面板，方便多檔重構任務中即時介入，同時修正前版將 Read 拒絕規則誤套用到 Bash 參數、導致常見 build/grep 指令在自動模式下被封鎖的問題。（9/3，[GitHub Releases](https://github.com/anthropics/claude-code/releases/tag/v2.1.260)）
- **GitHub Copilot 週更：三大新模型上線、舊模型將陸續淘汰**：GitHub Copilot 週更新增支援 Claude Fable 5.1、Gemini 3.8 Flash 與 GPT-6 Astra，並公告多款舊模型（如 Gemini 3.5/3.6 Flash、Claude Opus 4.7）將於 10/2 起陸續淘汰。（9/4，[GitHub Changelog](https://github.blog/changelog/2026-09-04-github-copilot-weekly-releases-august-31/)）
- **Claude Code 週限額「宣稱漲 25%、實則減 17%」爭議延燒 Hacker News**：Anthropic 原公告 9/14 起 Pro/Max/Team 方案週限額永久調漲 25%，但因先前臨時加碼 50% 即將到期，換算下來反而比現況少 17%，說法矛盾持續引發討論與挖苦。（9/5，[Hacker News](https://news.ycombinator.com/item?id=49506519)／[BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent/)）
- **資安焦點（僅摘要，不涉細節）：AI coding agent 遭爆供應鏈風險**：資安研究團隊揭露一類影響 Claude Code、Codex、Cursor 等多款 AI coding agent 的漏洞（研究方稱為 GitSpawn），部分廠商已修補、部分尚未修補，開發者應更新到最新版本並避免開啟不明來源的儲存庫。（9/2～9/4，[The Hacker News](https://thehackernews.com/2026/09/malicious-git-configs-can-make-claude.html)）
- **HN 熱議：「AI 代管事故，工程師正在失去系統直覺」**：工程師 Sylvain Kalache 撰文指出，AI 自動處理維運事故雖能降低平均修復時間，卻讓工程師少了從日常小事故中累積系統直覺的機會，一旦碰上 AI 無法處理的重大意外恐反應不及，該文登上 Hacker News 引發廣泛討論。（9/4，[Sylvain Kalache Blog](https://www.sylvainkalache.com/blog/ai-handles-incidents-engineers-lose-touch-with-their-systems)／[Hacker News](https://news.ycombinator.com/item?id=49574167)）
- **Sierra 開源 Hyper-τ-Bench：考驗 AI 能否「自己組裝」出一個 agent**：客服 AI 公司 Sierra 開源新基準，測試 coding agent 能否依雜亂的商業紀錄與需求文件自行建置客服代理，結果顯示最佳全自動化配置只通過 23.9% 評測任務，遠低於「工程師＋前沿模型」組合的 82.2%，凸顯「誰來組裝 agent」已成為比模型能力本身更棘手的課題。（9/8，[Unite.AI](https://www.unite.ai/sierra-open-sources-hyper-tau-bench-a-benchmark-for-agent-construction/)）
- **McKinsey 調查：近三分之一企業因 AI coding agent 放棄外購軟體**：McKinsey《State of AI》調查顯示，32% 受訪企業曾因能用 agentic coding 工具自行開發功能而放棄採購某項軟體，科技業比例高達 41%、健康照護業 39%，反映 AI coding agent 正改變企業「自建或外購」的決策。（9/6，[ANI News](https://aninews.in/news/business/ai-coding-agents-threaten-to-reshape-software-spending-as-companies-choose-to-build-rather-than-buy-mckinsey20260906210256/)）

## 國際經濟情勢
