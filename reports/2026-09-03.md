## AI 技術圈熱議

- **Anthropic 推出旗艦模型 Claude Fable 5.1，登上智慧指數榜首並成 Claude Code 新預設**：Anthropic 9/1 發表新旗艦模型 Claude Fable 5.1，在 Artificial Analysis Intelligence Index 拿下 66 分登頂各家模型，Claude Code 也同步將其設為預設模型。（9/1，[9to5Mac](https://9to5mac.com/2026/09/01/anthropic-upgrades-claude-with-new-fable-5-1-model-details-here/)）
- **「漲 25%」還是「砍 17%」？Claude Code 週限額公告惹議**：Anthropic 宣布 9/14 起週用量上限永久調高 25%，但因目前有到 9/14 為止的臨時 +50% 促銷，換算下來反而比現在實際少 17%，Hacker News 討論串發布不到一小時就被網友抓出算法問題並互相更正說法。（8/29，[Hacker News](https://news.ycombinator.com/item?id=49491631)）
- **OpenAI 因 SpaceX 收購 Cursor，宣布終止模型供應合約**：SpaceX 8/14 以約 600 億美元收購 AI 編碼工具 Cursor 後，OpenAI 8/29 宣布將終止供應模型給 Cursor（預計 11/12 斷供），理由是「無法信任 SpaceX 會遵守使用條款」，反映 Musk 與 OpenAI 長期恩怨；Cursor 執行長 Michael Truell 回應稱 OpenAI 模型僅占其流量約 5%，雙方仍在協商。（8/29，[CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)）
- **GitHub Copilot 大改計費與政策，將整併為單一 Agent 體驗**：GitHub 8/28 公告重新開放 Copilot Business／Enterprise 信用卡付款註冊、加嚴帳號審核，並預告雲端 Agent、網頁版與行動版 Chat 最快自 9/28 起整併為單一預設體驗，程式碼審查預設等級也將由 Lite 改為 Balanced。（8/28，[GitHub Changelog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)）
- **智譜 Z.ai 開源 GLM-5.3 權重（753B 參數），本地部署圈搶著實測**：GLM-5.3 8/14 先上 API，因在資安／漏洞挖掘任務表現突出、經歷延長的風險審查，權重延後兩週於 8/28 登上 Hugging Face，採附「大型 MaaS 業者需經安全審查」條款的專屬授權（非 MIT）。（8/28，[digitalapplied.com](https://www.digitalapplied.com/blog/glm-5-3-weights-bespoke-license-not-mit)）
- **Runway 發表「介面世界模型」Solaris，免寫程式即時生成可互動 App**：Runway 8/31 發表 Solaris，號稱首個「Interface World Model」，能逐格即時生成會回應點擊、拖曳與語音指令的軟體介面，尚未開放公測，技術圈熱議其對「no-code」開發模式的潛在衝擊。（8/31，[The Decoder](https://the-decoder.com/runways-solaris-is-an-ai-system-that-generates-software-interfaces-in-real-time/)）
